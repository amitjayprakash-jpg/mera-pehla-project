# मेरा पहला DevOps प्रोजेक्ट (My First DevOps Project)

यह एक साधारण HTML वेबसाइट है जिसे **Git** और **GitHub** के वर्कफ़्लो को समझने के लिए बनाया गया है।

## मुख्य विशेषताएं
- सरल और साफ HTML/CSS इंटरफ़ेस।
- Git के माध्यम से वर्जन कंट्रोल किया गया।
- स्पष्ट डॉक्यूमेंटेशन के लिए `README.md` शामिल है।

## इसे अपने कंप्यूटर पर कैसे चलाएं
1. इस रिपॉजिटरी को क्लोन करें:
   ```bash
   git clone https://github.comा-यूज़रनेम/mera-pehla-project.git
   ```
2. फोल्डर खोलें और `index.html` फाइल पर डबल-क्लिक करके उसे किसी भी वेब ब्राउज़र में देखें।
